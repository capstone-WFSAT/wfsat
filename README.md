## 독립 실행 HTML 교육용 대시보드 — `dashboard_html/index.html`
서버와 Python 없이 무선 공격 8종의 단계별 시각화 시뮬레이션을 실행한다.

- `dashboard_html/index.html`을 브라우저로 직접 열기
- 또는 프로젝트 루트에서 로컬 서버 실행:

```bash
python3 -m http.server 8080 --directory dashboard_html
```

브라우저에서 `http://127.0.0.1:8080`에 접속한다.
