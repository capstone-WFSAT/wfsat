# SSH로 대시보드 원격 열람

실습 호스트에서 본인 일반 사용자 계정으로 SSH 키 인증을 사용할 수 있어야 한다. 서버에 공개키를 등록하고, 처음 접속할 때는 실습 호스트의 SSH 호스트 키 지문을 확인한다. 브리지 포트 `5000`은 방화벽이나 공유기에서 외부로 개방하지 않는다.

1. 실습 호스트의 프로젝트 루트에서 일반 사용자로 브리지를 시작한다.

   ```bash
   WFSAT_HOST=127.0.0.1 WFSAT_PORT=5000 WFSAT_ENABLE_EXEC=0 python3 bridge.py
   ```

2. 외부에서 접속하는 기기의 PowerShell 또는 터미널에서 SSH 터널을 연다. `실습계정`과 `SSH서버주소`는 실제 값으로 바꾼다.

   ```text
   ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:5500:127.0.0.1:5000 실습계정@SSH서버주소
   ```

3. 터미널을 열어 둔 상태에서 같은 기기의 브라우저로 `http://127.0.0.1:5500/`을 연다. 이 구성에서는 시나리오와 저장된 탐지 결과를 열람할 수 있다. 접속을 마치면 터미널에서 `Ctrl+C`로 터널을 닫는다.

`5500`이 사용 중이면 SSH 명령의 첫 번째 포트와 브라우저 주소를 같은 빈 포트로 바꾼다. SSH 터널이 열려 있어도 페이지가 뜨지 않으면 실습 호스트에서 브리지가 실행 중인지, 명령에 지정한 서버 측 주소와 포트가 일치하는지 확인한다.

## 콘솔에서 저장된 탐지 결과 조회

위 브리지 실행 명령 대신 다음 명령을 사용한다. 외부 기기에서는 같은 SSH 터널과 브라우저 주소를 사용한다.

```bash
WFSAT_HOST=127.0.0.1 WFSAT_PORT=5000 WFSAT_REPORT_ONLY=1 WFSAT_ENABLE_EXEC=1 python3 bridge.py
```

실습 탭 콘솔에서 `report`를 입력하면 `WFSAT_DETECT_JSON`에 지정된 탐지 결과의 AP 목록과 탐지 항목이 표시된다. 기본 경로는 `/tmp/et_logs/detect.json`이다. 결과가 없으면 빈 목록을 표시한다. 이 모드는 인자 없는 `report`만 허용하고, 이벤트 입력 및 실행 로그 조회에는 `403`을 반환한다.

탐지 결과에 Beacon 타임라인이 포함되어 있으면 같은 실습 탭의 **Beacon Flood 패킷 분석**에서 초별 프레임을 열람할 수 있다.

Evil Twin 학습 화면은 준비된 예시 데이터를 사용한다. 피해 기기 관찰 기록은 입력한 브라우저에 저장된다. PCAP에서 추출한 Evil Twin 연결 타임라인은 오프라인 분석 파일에서 확인할 수 있다.
